# 文字を描く手段の試し

Seinasが自分で描く文字に使う手段を、実際に試して比べるためのコードです。本体には組み込んでいません。
結果と、推す案は、`docs/text-rendering.md` にまとめてあります。

本体のワークスペースとは別になっています(依存も `Cargo.lock` も別)。ビルドは、このディレクトリで行います。

| 場所 | 中身 |
| --- | --- |
| `common/` | どの候補にも共通の部分(試す文字列、描く先、画像の書き出し、速さとメモリーの記録) |
| `try-baseline/` | 比べるための土台。文字を描く手段を何も入れない |
| `try-cosmic/` | cosmic-text + swash |
| `try-swash/` | swashだけ |
| `try-fontdue/` | fontdue |
| `run.sh` | 一通り動かして、画像と記録を `out/` に作る |
| `sheets.py` | 画像(PPM)を、見比べ用のPNGにまとめる |
| `deps.py` | 候補ごとに、依存のクレートの数とライセンスの内訳を出す |

## 動かし方

```bash
../../tools/fetch-fonts.sh
```

```bash
./run.sh
```

実行ファイルの引数は、順に、フォントの置き場所、出力先、`nohint`(字形のヒンティングを切る)、控えとして足すフォントのファイル(`try-cosmic` だけ)です。
