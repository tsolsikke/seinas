# ADR 0007: アプリのアイコンのために、PNG を読むクレートを、タスクバーとコンポジタへ広げる

## 状態

決定(2026-10-26。運用者の決定)。

## 背景

- 壁紙(seinas-wallpaper)を足したとき(2026-10-11)に、PNG を読むクレート(png 0.18.1)を、壁紙のほかに入れない決まりを置いた。CI と `tools/pre-push.sh` の full の段で、seinas-standalone・seinas・seinas-taskbar に png が入っていないことを確かめていた。コンポジタの依存を少なく保ち、画像を読む所を、コンポジタと別のプロセスに置くためである。
- 見た目の仕様(`docs/ui-spec.md`)で、タスクバーのタスクと、ウィンドウのタイトルバーの左に、アプリのアイコンを出すことにした。アイコンは、freedesktop の決まりのとおり、データの置き場の PNG から読む(app_id → `.desktop` の `Icon` → アイコンのテーマ hicolor → `pixmaps`)。
- PNG を読めないと、どのアプリも既定のアイコンになる(2026-10-26 の途中の形)。

## 比べた案

| 案 | 良い点 | 悪い点 |
| --- | --- | --- |
| A. png を、アイコンのクレート(seinas-icons)に入れ、タスクバーとコンポジタで読む(採った) | Cargo.lock に新しいクレートは増えない(壁紙と同じもの)。タスクバーとタイトルバーの両方で、同じ探し方と読み方を使える | コンポジタの依存が増える(png とその依存)。コンポジタの中で、ファイルの画像を展開する |
| B. タスクバーにだけ入れ、コンポジタには入れない | コンポジタの依存は今のまま | タイトルバーのアイコンが、いつも既定のアイコンになる |
| C. 依存を入れず、PNG(zlib の展開を含む)を自前で読む | 依存が増えない | 保守と安全の手間が大きい |
| D. しばらく既定のアイコンのまま | 何も変えない | 仕様の見た目にならない |

## 決定

案 A を採る。コンポジタの依存を少なく保つ決まりを、アイコンのために、次の条件で広げる。

1. png を直に使ってよいのは、seinas-wallpaper と seinas-icons だけ。タスクバーとコンポジタは、seinas-icons を通してだけ使う。CI と `tools/pre-push.sh`(full)は、`tools/check-deps.sh --direct-users png seinas-wallpaper seinas-icons` で、それ以外のパッケージが直に使ったら落ちる形を保つ。fbdev のバックエンド・共通のレンダラー・文字・zeyes-min・テスト用のクライアントには、png が入らないことも確かめる。
2. 読むのは、データの置き場(XDG のディレクトリの `icons` と `pixmaps`)のファイルだけ。`.desktop` に絶対パスのアイコンが書いてあっても、データの置き場の外のファイルは読まない。クライアントから受け取った画像は読まない。
3. 読む前に上限を確かめる。越えたもの・読めないものは、既定のアイコンにして、ログに 1 行出す。
   - ファイルの大きさは 1 MiB まで(`MAX_ICON_FILE_BYTES`)。アイコンのテーマの PNG は、いちばん大きい 512x512 でも、ふつうは数百 KB に収まる。これを越えるものは、読み始めない。
   - 幅と高さは 512 まで(`MAX_ICON_SIDE`)。hicolor のいちばん大きい大きさまで。これより大きな画像は、どうせ 24 や 20 に縮めるので要らない。画像のデータを読む前(見出しで)に断る。展開した絵は、上限でも 1 MiB(1 ピクセル 4 バイト)に収まる。
4. 読んだものは、app_id ごとに覚えて使い回す(毎回は読まない)。

## 結果

- 実行ファイルの大きさ(musl の release、2026-10-26):seinas-taskbar は 5,005,176 → 5,172,808 バイト(+167,632)。コンポジタは、タイトルバーのアイコンと枠・角・影を入れた後で、seinas-standalone が 9,096,384 → 9,350,920 バイト(+254,536)、seinas が 10,030,104 → 10,303,808 バイト(+273,704)。コンポジタの差には、png とその依存のほかに、アイコンを探して読む所(seinas-icons)と、枠・角・影のコードも入る。
- release の第三者のライセンス文(`tools/release-notices.py` が実行ファイルごとに集めるもの)に、png とその依存(fdeflate・flate2・miniz_oxide・crc32fast・adler2 など)が、タスクバー(と、タイトルバーのアイコンを入れた後のコンポジタ)の分でも入る。`THIRD-PARTY/` の一覧そのものは、Cargo.lock のクレートが変わらないので変わらない。
- ZeikOS の上でアイコンを読むには、データの置き場(とアイコンの置き場所)を決める必要がある(未決)。見つからなければ、既定のアイコンで動く。
