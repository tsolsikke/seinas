# 用語と書き方

Seinas のコミットメッセージ、ドキュメント、コードコメントでの、用語の選び方です。

## 決まり

- IT 用語は、無理に和語へ言い換えません。一般的な IT 用語(カタカナ語・英語の用語)を、そのまま使います(運用者の決定。2026-10-08)。
- 文章そのものは、これまでどおり、柔らかく分かりやすい自然な日本語で書きます。
- 既存のドキュメントとコメントは、一括では書き換えません。新しく書くものと、別の理由で触った箇所だけを、この書き方にします(一括の書き換えは、別の課題で行います)。
- そのため、しばらくは古い言い方と新しい言い方が混ざります。下の対応表で読み替えてください。
- 課題キーの位置や、コミットメッセージの行数など、ほかの決まりは変わりません。

## 使わない語(pre-push で止める)

IT の意味では、左の語を使いません。「使う語」を使います(運用者の決定。2026-10-16。zeikos のリポジトリの `docs/terminology.md` の「使わない語」の表に合わせたもの)。

`tools/old-terms.py` がこの表を読み、新しく書いた行に「当たる形」があると、`tools/pre-push.sh` の「古い言い方」の確かめを落とします(下の対応表の言葉は、これまでどおり表示するだけです)。列の読み方は次のとおりです。

- 当たる形:探す文字列。インラインコードで書き、複数ならコードを並べます。
- 除く形:当たる形を含むが、一般の意味である語。この中に収まる当たりは数えません。
- 当たる形の直後に「→」が続く所は、言い換えの例なので数えません(`CLAUDE.md` の例がこれです)。

| 使わない語 | 使う語 | 当たる形 | 除く形 | 備考 |
| --- | --- | --- | --- | --- |
| 像 | イメージ | `像` | `写像` `想像` `画像` `映像` `解像` `実像` `虚像` `肖像` `偶像` `残像` `群像` `鏡像` `全体像` `像を結` | メモリーに置いたときのイメージ |
| 写像 | マッピング、マップする | `写像` | | mmap の意味 |
| 番地 | アドレス | `番地` | | |
| 葉 | リーフ | `葉` | `言葉` `葉書` `千葉` `紅葉` `若葉` `枯葉` `落葉` `松葉` | |
| 区画 | セグメント(ELF)、パーティション(GPT) | `区画` | | 意味ごとに分ける |
| 画素 | ピクセル | `画素` | | |
| 裏バッファ | バックバッファ | `裏バッファ` | | |
| 窓 | ウィンドウ | `窓` | `窓口` | 候補の窓は候補ウィンドウ |
| 錠 | ロック | `錠` | `錠剤` | |
| 鍵 | キー、ロック | `鍵` | `打鍵` `離鍵` `鍵盤` | 鍵のファイルはロックファイル。連想・キャッシュ・署名の鍵はキー |
| 旗 | フラグ | `旗` | | |
